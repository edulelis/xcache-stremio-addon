# Security

XCACHE is self-hosted. The public repository and GitHub Pages configurator must never contain runtime secrets.

## Secrets

Keep these values only in your private `.env` or secret manager:

- `INSTALL_TOKEN_SECRET`
- `QBITTORRENT_PASS`
- `REAL_DEBRID_API_TOKEN`
- reverse proxy credentials
- cookies or API captures

The install token generated by `npm run print-token` is safe to use in your Stremio manifest URL, but treat it as private enough to rotate if it is shared accidentally.

## Network Exposure

- Expose `xcache-addon` publicly through HTTPS.
- Do not expose qBittorrent WebUI publicly.
- Keep qBittorrent reachable only inside Docker or a private network.

## Cache Safety

XCACHE should only delete files inside `CACHE_DIR`. If you change cache cleanup behavior, add tests that prove paths outside `CACHE_DIR` are rejected.

## Reporting Issues

When reporting bugs, remove tokens, passwords, cookies and private domains from logs before sharing them.
